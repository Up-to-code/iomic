# Iomic

Iomic application source built with React.

[Source](https://github.com/Up-to-code/iomic) · [Issues](https://github.com/Up-to-code/iomic/issues) · [Project directory](https://github.com/qentrah/.github/blob/main/profile/PROJECTS.md)

## Technology

React, Vite, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/iomic.git
cd iomic
```

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Development server |
| `npm run build` | Build the project |
| `npm run lint` | Check lint rules |
